# <p id='about'>About the Project </p> 
This is python Flask E-commerce Web App built with html, CSS & JavaScript. I have divied the project into 3 different module and register them with the app with Blueprint inside \__init__.py file,  
* <a href='#product'>Product</a>
* <a href='#users'>users</a>
* <a href='#admin'>Admin</a>  

The entry point of the application is app.py
